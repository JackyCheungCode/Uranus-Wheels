# Uranus Wheels — Vehicle Fitment Reference Standard

Status: Required editorial and engineering standard for published vehicle guides.

## 1. Scope

Every published fitment value must be tied to an exact vehicle scope. A chassis code alone is not sufficient when model year, edition, drivetrain, brake package, market or axle configuration changes compatibility.

Required scope fields:
- Make, model and chassis code
- Model year or production-date range
- Edition / trim
- Market / homologation region where relevant
- Drivetrain
- Brake package / caliper configuration
- Axle: front, rear or both
- Tire make/model and size when a complete setup is being documented

## 2. Evidence hierarchy

Use evidence in this order, recording the actual source for each claim:

1. OEM technical documentation, parts catalogue, owner's documentation or official technical bulletin.
2. Physical measurement on an identified vehicle, with measurement method and equipment recorded.
3. Wheel or component manufacturer's engineering drawing, clearance template or application-specific technical confirmation.
4. Documented professional installation / test-fit report with vehicle identity, hardware and photographs.
5. Owner build record with sufficient vehicle and component detail. Treat as supporting evidence, not engineering approval.

Unattributed forum posts, scraped fitment tables, AI-generated answers and unsupported seller claims must not be used as sole evidence for a Verified value.

## 3. Citation format

Use stable source IDs, displayed inline next to the value and repeated in a source register.

Recommended ID format:
- `UW-M4-G82-001` — vehicle/guide-specific source
- `UW-M4-F82-001` — source for another chassis
- `UW-GLOBAL-0001` — source applicable across multiple guides

Every source record must contain:
- Source ID
- Publisher / author
- Document or page title
- Document number and page / section, if available
- Canonical URL or internal document reference
- Publication date and access date
- Evidence type
- Exact vehicle scope supported
- Exact specification fields supported
- Reviewer and review date
- Notes, limitations and superseded-source relationship

A citation must support the specific value beside it. A general model brochure must not be cited as evidence for an aftermarket wheel offset or brake clearance.

## 4. Fitment record requirements

For wheel setups, record front and rear independently:
- Diameter and width
- Offset (ET)
- PCD / bolt pattern
- Center bore and hub interface
- Fastener thread, length and seat
- Tire size, make/model and measured dimensions when available
- Load rating and vehicle axle-load basis
- Brake caliper / barrel / spoke clearance
- Fender, suspension and steering clearance
- Ride height and alignment assumptions
- Intended use: street, sport, track or show

Do not infer an approved offset range from an OEM wheel, a flush-fitment photo or a maximum-size claim.

## 5. Publication statuses

- Draft — incomplete data; internal only.
- Engineering Review — evidence exists but compatibility review is not complete.
- Verified — exact vehicle and component combination has documented evidence and review.
- Published — approved for public display, with scope, caveats and citations visible.

A record can be Verified for one trim / brake package and remain unverified for another. Do not promote a whole chassis family based on one vehicle.

## 6. Public presentation

- Show front and rear values separately.
- Display source IDs next to values, with a source register.
- Identify OEM specification, aftermarket reference, measured result and calculated value distinctly.
- Show unknown or unverified data as unavailable; never silently fill gaps.
- Display the exact vehicle scope and date of last review.
- State that a database match is not a substitute for a physical clearance check where required.

## 7. Editorial and legal guardrails

Uranus Wheels is an independent aftermarket brand. Do not imply BMW ownership, sponsorship or endorsement. Do not publish safety, load, road-legality or performance claims without supporting evidence and appropriate regional context.
